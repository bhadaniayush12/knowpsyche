## Test 3 — Photographic Memory

A grid lights up for a moment; the user rebuilds the pattern. Target keyword: "photographic memory test" (\~2.4K US/month, easy to rank).

### Page copy

| Field | Text |
| --- | --- |
| URL | /photographic-memory-test/ |
| Google title | Photographic Memory Test — How Much Can You Remember? |
| Meta description | Study a grid for a second, then rebuild it. Each level adds a tile. Free, instant, no sign-up — see how sharp your visual memory really is. |
| H1 | Photographic memory test |
| Intro | Some tiles will light up for a moment. Click the same tiles once they disappear. Each level adds one more. |

### How the test works

- **Level 1:** a 3×3 grid, 3 tiles light up for 1.2 seconds.
- Each level adds one tile. The grid grows to 4×4 at level 4, 5×5 at level 8, and 6×6 at level 12.
- The user clicks tiles in any order. A correct tile turns teal; a wrong one turns coral.
- **3 lives.** One wrong tile = lose a life and repeat that level with a new pattern. Lose all 3 and the test ends. When the grid grows (levels 4, 8 and 12), show one short line for 1 second before that level starts: "Bigger grid. Try seeing the tiles as shapes."

### Scoring

- **Score** = highest level fully completed.
- **Also shown:** total tiles remembered, and lives left.

### Result bands (our guide, not norms)

| Level reached | Badge | What we say |
| --- | --- | --- |
| 1–4 | Warming up | Short-term visual memory has limits for everyone. Try again — it often improves on the second go. |
| 5–8 | Solid | You hold a fair amount of detail from a quick look. |
| 9–12 | Sharp | You keep a lot of visual detail in mind at once. |
| 13+ | Exceptional | Very few patterns get past you. |

### Result copy

- **What does it mean?** \[band text\]. You remembered \[N\] tiles in total.
- **What can change it?** Focus, tiredness and strategy. Many people do better by grouping tiles into shapes instead of remembering single squares.
- **What next?** Try Number memory to compare how you hold numbers versus pictures.

### FAQ

1. **Is photographic memory real?** A perfect, camera-like memory in adults has little solid evidence. Some children show vivid "eidetic" images, but this is rare and fades with age.
2. **What does this test actually measure?** Visual short-term memory — how many locations you can hold in mind for a few seconds.
3. **How many things can we remember at once?** Classic research suggests visual short-term memory holds only a handful of items at a time, often around four.
4. **Can I improve my visual memory?** Practice helps, and so does grouping tiles into shapes or patterns.
5. **Is this a medical test?** No. It's for curiosity and self-reflection.

### Sources

- Luck, S. J., & Vogel, E. K. (1997). The capacity of visual working memory for features and conjunctions. *Nature*.
- Haber, R. N. (1979). Twenty years of haunting eidetic imagery. *Behavioral and Brain Sciences*.

## Test 4 — Number Memory

A number flashes up; the user types it back. One digit longer each round. Target keyword: "number memory test".

### Page copy

| Field | Text |
| --- | --- |
| URL | /number-memory-test/ |
| Google title | Number Memory Test — How Many Digits Can You Hold? |
| Meta description | Remember a number, then type it back. It grows by one digit each round. Free, instant, no sign-up — find your digit span. |
| H1 | Number memory test |
| Intro | A number will appear for a few seconds. When it disappears, type it in. Each round adds one digit. |

### How the test works

- **Round 1:** a 3-digit number. Each correct answer adds one digit.
- **Display time** = 1 second + 0.6 seconds per digit (3 digits = 2.8 s; 10 digits = 7 s), with a shrinking bar showing time left. When the number first reaches 7 digits, show a one-time tip before it appears: "Tip: try splitting it into groups of 2 or 3."
- The number never starts with 0, and never repeats the same digit three times in a row.
- **2 lives.** One wrong answer = lose a life and try the same length again with a new number.
- After a wrong answer, show the right number and the user's answer, with the mismatched digits highlighted. If the mistake is in the middle, add: "Most people lose track in the middle. The first and last digits are usually the easiest to hold."

### Scoring

- **Score** = longest number typed correctly (the user's "digit span").

### Result bands (our guide, not norms)

| Digits | Badge | What we say |
| --- | --- | --- |
| 3–5 | Warming up | Numbers slip away quickly for many people. Try grouping them. |
| 6–7 | Typical | Right around where most people land. |
| 8–9 | Strong | You hold more digits than most. |
| 10+ | Exceptional | You're likely using a smart strategy, like chunking. |

### Result copy

- **What does it mean?** You held \[N\] digits. \[band text\].
- **What can change it?** Strategy matters most. Reading 49 21 73 as three chunks is easier than six single digits. Tiredness and distractions lower scores.
- **What next?** See how your visual memory compares in the Photographic memory test.

### FAQ

1. **What is digit span?** The longest string of numbers you can repeat back right after seeing or hearing it. It's a classic way to measure short-term memory.
2. **What is a normal digit span?** A famous 1956 paper suggested people hold about "seven, plus or minus two" items. Later research suggests our true limit is closer to four chunks.
3. **How can I improve my number memory?** Group digits into chunks of two or three, say them in a rhythm, or link them to dates you know.
4. **Is this a medical test?** No. It's for curiosity and self-reflection.

### Sources

- Miller, G. A. (1956). The magical number seven, plus or minus two. *Psychological Review*.
- Cowan, N. (2001). The magical number 4 in short-term memory. *Behavioral and Brain Sciences*.

## Test 5 — Attention Span

A real Go/No-Go task: click for green, hold back for red. Three scores, about 2.5 minutes. Target keyword: "attention span test".

### Page copy

| Field | Text |
| --- | --- |
| URL | /attention-span-test/ |
| Google title | Attention Span Test — How Well Do You Stay Focused? |
| Meta description | Click for green, hold back for red. A 2-minute focus test based on a classic psychology task. Free, instant results for focus and self-control. |
| H1 | Attention span test |
| Intro | Circles will appear one at a time. Click (or tap) when you see green. Do nothing when you see red. Stay with it — it's longer than it feels. |

### How the test works

- **Practice:** 6 rounds with feedback ("Nice!" / "Oops — that was red"), not scored.
- **Main test:** 80 circles. 75% green (60), 25% red (20), in random order, never more than 2 reds in a row.
- Each circle shows for 0.5 s. The gap between circles varies from 0.8 to 1.6 s, so the rhythm can't be predicted.
- Click/tap anywhere in the box, or press the spacebar.
- A thin progress bar runs along the top. No feedback during the main test, so the user stays in flow.

### Scoring

| Score | How it's calculated | What it reflects |
| --- | --- | --- |
| Focus | % of green circles clicked in time | Staying on task |
| Self-control | % of red circles correctly ignored | Holding back an automatic response |
| Speed | Average time to click on greens (ms) | How quickly you respond |
| Steadiness | Compares the first half with the second half | Whether focus faded over time |

**Overall attention score** = average of Focus and Self-control, out of 100.

### Result bands (our guide, not norms)

| Overall | Badge | What we say |
| --- | --- | --- |
| Under 70 | Drifting | Your focus wandered or you clicked on reds. Very common when tired or distracted. |
| 70–84 | Steady | You stayed with the task most of the time. |
| 85–94 | Focused | Strong focus and good self-control. |
| 95+ | Laser | You barely missed a thing. |

### Result copy

- **What does it mean?** \[band text\]. You caught \[X\]% of greens and held back on \[Y\]% of reds. \[If second half was worse by 5+ points: "Your focus dipped in the second half — that's normal; attention tires with time."\]
- **What can change it?** Sleep, phone notifications, noise and how interested you are in the task.
- **What next?** Try the Stroop test — it puts your focus up against your reading habit.

### FAQ

1. **What is attention span?** How long you can keep your focus on one task. It isn't one fixed number — it changes with the task, your mood and how tired you are.
2. **Is the average attention span really 8 seconds, shorter than a goldfish?** No. That claim is widely repeated but has no solid research behind it.
3. **What is a Go/No-Go task?** A classic psychology task: respond to one kind of signal and hold back on another. It measures focus and self-control together.
4. **How can I improve my attention span?** Remove notifications, work in focused blocks (for example 25 minutes), sleep well, and take short breaks before you're exhausted.
5. **Can this test tell if I have ADHD?** No. It's not a diagnosis. If focus problems affect your daily life, talk to a doctor or psychologist.

### Sources

- Gomez, P., Ratcliff, R., & Perea, M. (2007). A model of the go/no-go task. *Journal of Experimental Psychology: General*.
- Donders, F. C. (1969). On the speed of mental processes (W. G. Koster, Trans.). *Acta Psychologica*, 30, 412–431. (Original work published 1868; the first go/no-go style reaction task.)

## Test 6 — Stroop Test

Pick the ink colour, not the word. The score is how much the clashing words slow you down. About 1 minute. Target keyword: "stroop test".

### Page copy

| Field | Text |
| --- | --- |
| URL | /stroop-test/ |
| Google title | Stroop Test — Can Your Brain Ignore the Word? |
| Meta description | Name the ink colour, not the word. A 1-minute version of a famous 1935 experiment. See how much clashing words slow you down — free, instant. |
| H1 | Stroop test |
| Intro | A colour word will appear in coloured ink. Click the button for the INK colour — ignore what the word says. Be fast, but accurate. |

### How the test works

- **4 colours:** red, blue, green, yellow. 4 buttons with the colour name and a colour swatch. Keyboard: R, B, G, Y.
- **Practice:** 4 rounds with feedback.
- **Main test:** 40 words in random order: 20 **matching** ("BLUE" in blue) and 20 **clashing** ("BLUE" in red). The same word never appears twice in a row.
- The word stays until the user answers (max 3 s, then it counts as missed). 0.4 s gap between words.
- **Colour vision note** above the test: "This test relies on telling colours apart, so it may not work well for people with colour-vision differences."

### Scoring

- **Stroop effect** = average time on clashing words − average time on matching words (correct answers only), in ms.
- **Accuracy** = % correct overall.
- **Also shown:** average time for each type, as two bars.

### Result bands (our guide, not norms)

| Stroop effect | Badge | What we say |
| --- | --- | --- |
| Under 80 ms | Unshakeable | The clashing words barely slowed you down. |
| 80–160 ms | Typical | Your brain read the word anyway, like almost everyone's does. |
| 161–250 ms | Word-pulled | The words pulled hard on your attention. |
| Over 250 ms | Strongly pulled | Reading is very automatic for you — the words won the tug-of-war. |

If accuracy is under 85%, add: "You were fast but made several mistakes — try again a little slower for a fairer score."

### Result copy

- **What does it mean?** Clashing words slowed you down by \[X\] ms. \[band text\].
- **What can change it?** Reading speed, practice, tiredness and how fast you try to go.
- **What next?** Try the Attention span test to see how well you hold back an automatic response.

### FAQ

1. **What is the Stroop effect?** Naming the ink colour takes longer when the word names a different colour. Reading is so automatic that it gets in the way.
2. **Who discovered it?** J. Ridley Stroop, in experiments published in 1935.
3. **What does the Stroop test measure?** How well you can focus on one thing (the ink) while ignoring a strong habit (reading the word).
4. **Is a bigger Stroop effect bad?** Not really — it mostly shows how automatic your reading is. It's a fun look at how your attention works, not a grade.
5. **Is this a medical test?** No. It's for curiosity and self-reflection.

### Sources

- Stroop, J. R. (1935). Studies of interference in serial verbal reactions. *Journal of Experimental Psychology*.
- MacLeod, C. M. (1991). Half a century of research on the Stroop effect. *Psychological Bulletin*.

## Test 7 — Emotional Intelligence

### Page copy

- **URL:** `/emotional-intelligence-test/`
- **Title tag:** Emotional Intelligence Test (Free, 28 Questions) | KnowPsyche
- **Meta description:** A free, private emotional intelligence test. 28 quick statements on how you notice, manage and read feelings, yours and other people's. Results in about 5 minutes, never stored.
- **H1:** How do you handle feelings?
- **Intro:** Emotional intelligence is how well you notice feelings, yours and other people's, and what you do with them. Rate 28 statements about how you usually act. There are no right answers, only honest ones. Your result shows four areas, so you can see where you're already strong and what's worth practising.
- **Time:** about 5 minutes · **Questions:** 28 · **Saved:** nothing

### How it works

Each statement is rated on a 1–5 scale: 1 Not like me · 2 A little like me · 3 Somewhat like me · 4 Mostly like me · 5 Very like me.

One statement per screen, keyboard keys 1–5 work, a back button lets people change the last answer. A thin progress line shows 7 of 28 and so on. Items are shown in a fixed mixed order (areas interleaved) so the same area never appears twice in a row.

### The 28 statements (original, written for KnowPsyche)

(R) = reverse-scored.

**Area 1 — Knowing your feelings (self-awareness)**

1. I can usually name what I'm feeling, not just "good" or "bad".
2. I notice when my mood starts to change, before it takes over.
3. I know which situations tend to stress me out.
4. Sometimes I'm upset and have no idea why. (R)
5. I can tell how my feelings are shaping a decision I'm making.
6. I understand what my strong reactions say about what matters to me.
7. Other people often notice my mood before I do. (R)

**Area 2 — Managing your feelings (self-management)**

8. When I'm angry, I can pause before I say something I'd regret.
9. I can calm myself down after a stressful moment.
10. A bad mood in the morning usually ruins my whole day. (R)
11. I can keep working on something even when I don't feel like it.
12. When plans fall apart, I adjust instead of shutting down.
13. I often act on impulse and wish I hadn't. (R)
14. I can stay hopeful when things are hard for a while.

**Area 3 — Reading other people (social awareness)**

15. I can tell how someone feels from their face or tone, even if they don't say it.
16. I notice when someone in a group feels left out.
17. I can see a situation from someone else's side, even when I disagree.
18. People sometimes surprise me by being upset with something I said. (R)
19. I can sense the mood of a room when I walk in.
20. I pay attention to what people mean, not only what they say.
21. I find it hard to understand why people react the way they do. (R)

**Area 4 — Handling relationships (relationship skills)**

22. I can tell someone they've upset me without starting a fight.
23. When friends argue, I can help them hear each other.
24. I find it easy to say sorry when I get something wrong.
25. I avoid hard conversations even when they need to happen. (R)
26. People come to me when they need to talk.
27. I can say no without feeling guilty for days.
28. I tend to give up on people after one disagreement. (R)

### Scoring

1. Reverse items (4, 7, 10, 13, 18, 21, 25, 28): score = 6 − answer.
2. Area score = (sum of its 7 items − 7) ÷ 28 × 100, rounded. Range 0–100.
3. Overall score = average of the 4 area scores, rounded.
4. If someone answers every item with the same number (all 1s, all 3s, all 5s), show a soft note: "You gave every statement the same answer. Your result may be less useful. Want to try again?" Still show the result.

### Bands (our guide, not a norm)

- **Under 50 — Growing:** this area is still developing. Totally normal; it improves with practice.
- **50–70 — Solid:** you handle this well most of the time.
- **70–85 — Strong:** a clear strength for you.
- **85+ — Very strong:** something people probably rely on you for.

Below the bands, always: "These bands are our own guide to help you read your result. They're not compared with a population, and they're not a diagnosis."

### Result copy

**Headline:** shows the strongest area. Example: "Your strongest area: Reading other people." Then four bars with the area score and band word. If two areas tie, show both.

**Knowing your feelings**

- High: You usually know what you feel and why. That makes it easier to choose how to respond instead of just reacting.
- Lower: Feelings sometimes show up before you can name them. That's common, and it gets easier.
- Try this: Once a day, stop and name your feeling in one specific word ("restless", "proud", "left out"). Naming a feeling is one of the simplest ways to get some distance from it.

**Managing your feelings**

- High: Strong feelings don't easily push you around. You can pause, reset and keep going.
- Lower: Big feelings can take the wheel for a while. That's human, and it's a skill you can build.
- Try this: When you feel the surge, take three slow breaths before you reply. Even a short pause gives you more choice about what you say next.

**Reading other people**

- High: You pick up on how people feel, even when they don't say it. People likely feel understood around you.
- Lower: Other people's feelings can be hard to read. Asking is a perfectly good substitute for guessing.
- Try this: In your next conversation, ask one "how did that feel?" question and really listen to the answer.

**Handling relationships**

- High: You can handle the hard parts of relationships: saying sorry, saying no, talking through a conflict.
- Lower: Tough conversations may feel easier to avoid. Small, honest steps help.
- Try this: Next time something bothers you, say it early and simply: "When X happened, I felt Y."

**Kind closing line (always shown):** "Emotional intelligence isn't fixed. Everyone's result moves as they practise. Come back in a few months and see what's changed."

### After the result

- Share card: overall score + strongest area + "knowpsyche.com". No weaker areas on the card.
- Next test suggestion: Enneagram ("See what drives you underneath").
- Learn link: "What is emotional intelligence, really?" (future article).

### FAQ

**What is emotional intelligence?** It's the ability to notice, understand and manage feelings, both your own and other people's. Psychologists Peter Salovey and John Mayer described it in 1990, and Daniel Goleman's 1995 book made the idea popular.

**Is EQ more important than IQ?** They measure different things. IQ tests are about reasoning and problem-solving; emotional intelligence is about feelings and relationships. Both matter, in different situations. Claims that EQ "matters twice as much" as IQ aren't well supported by research.

**Can you improve your emotional intelligence?** Yes. These are skills, not fixed traits. Practising things like naming feelings, pausing before reacting and asking people how they feel can help over time.

**How accurate is this test?** It's a self-report test, so it shows how you see yourself. That's useful, but people don't always see themselves clearly. For a fuller picture, ask someone who knows you well how they'd answer a few of the statements about you.

**Is this a clinical or professional assessment?** No. It's an educational self-reflection tool, not a diagnosis, and it can't be used for hiring or clinical decisions. If you're struggling with your emotions, talking to a qualified professional is a good step.

**Do you save my answers?** No. Everything is calculated in your browser and disappears when you close the page.

**How long does the test take?** About 5 minutes. There are 28 statements and no time limit.

**What's a good emotional intelligence score?** There's no pass mark. Our bands (Growing, Solid, Strong, Very strong) are a simple guide we made to help you read your result. They aren't compared with other people.

### Sources

- Salovey, P., & Mayer, J. D. (1990). Emotional intelligence. *Imagination, Cognition and Personality*, 9(3), 185–211.
- Goleman, D. (1995). *Emotional Intelligence: Why It Can Matter More Than IQ*. Bantam Books.
- Note for the page: the four areas follow the common self-awareness / self-management / social awareness / relationship skills grouping. All 28 statements are our own writing; we do not use any published, copyrighted EQ questionnaire.

## From the outside review (13 Oct): what we took and what we didn't

The long psychology write-up was checked against our rules. Most of its useful ideas were already in this doc (chunking tips, highlighted wrong digits, the visual-vs-numbers link, the second-half focus note, the Stroop accuracy note).

**Added from it**

- Photographic memory: a short "Bigger grid" line when the grid grows.
- Number memory: a one-time grouping tip at 7 digits, and a line explaining that most people slip in the middle of the number.
- Attention span: Donders (1868) added as a source, since his task is where go/no-go started.

**Left out, and why**

- "Top 1%", "Top 5%" and similar lines on badges and share cards: we have no data behind them.
- Brain-region language (prefrontal cortex, amygdala, ACC, limbic system): breaks the no-biology-jargon rule, and many of those claims are oversimplified.
- Jargon progress captions like "Exceeding Cowan's 4-chunk threshold": they sound like science but mean nothing to the reader, and they distract mid-test.
- Badge names like "Eidetic Visualizer" or "Gestalt Architect": "eidetic" suggests a photographic memory, which our own FAQ says is very rare.
- "Ego-bait" share text and a combined "7-dimensional psychological blueprint": that would present seven separate quiz scores as one validated profile, which it isn't.
- Enneagram "subconscious drivers": a claim we can't support. Part 1's wording stays.
- EQ bands like "Hyper-Attuned Sensor (Perceptive but Vulnerable)": Barnum-style labels that fit almost anyone.
- "6-second pause lets chemicals reach your thinking brain": a popular claim without solid evidence. Our "three slow breaths" tip makes no such claim.
- New band cut-offs and type names for Reaction Time and Enneagram: Part 1 already has ours, so we keep them.

**Considered for v1.1:** scenario-based EQ questions ("Your friend cancels last minute. What do you do?"). The review is right that self-report shows how people see themselves, not what they actually do. But scenarios need answer keys we'd have to justify carefully, so launch stays with 28 statements plus the honest "How accurate is this test?" FAQ.

## Shared rules for all 7 tests

These apply to every test page, Part 1 and Part 2. The build should follow them without needing to check each test.

### Writing

- Plain English, short sentences. Psychology words only when explained in the same line.
- No biology jargon on test or result pages (no brain-region names, no neurotransmitters).
- Never say "MBTI", "IQ score", "brain age" or "diagnosis" as something we give.
- Results talk to the person kindly. A low score is framed as "still developing" or "room to grow", never as a failure.
- No Barnum copy (vague statements that fit everyone). Every result line must depend on the actual score.

### Numbers and claims

- All bands are labelled as **our guide**, with this line under every result: "These bands are our own guide to help you read your result. They're not compared with a population, and they're not a diagnosis."
- No percentiles, "top X%", or "better than X% of people" unless we have real data behind it. We don't, so none at launch.
- Any fact about research names its source in the Sources list at the bottom of that page.

### Privacy

- Every score is calculated in the browser. Nothing is sent to a server, stored or linked to a person.
- No email gate, no sign-up, no "unlock your full result".
- Same line on every test page near the Start button: "Private by design: your answers never leave this page."
- Analytics (when added) count page views and test completions only, never answers or scores.

### Test experience

- Ads never appear inside a running test or between questions. Allowed spots: below the intro text, below the result, and inside the FAQ area.
- Every test works fully with a keyboard. Timed tests use Space or Enter; question tests use keys 1–5 (or the shown option keys).
- Respect reduced motion: when the user has it on, no animated transitions, only instant swaps. Timing tests still work normally.
- Focus states visible on all buttons; colour is never the only signal (Stroop is the one test where colour IS the task, so it adds a short note for colour-blind users and allows a skip).
- Mobile first: tap targets at least 44px; timed tests on phones say "tap" instead of "press Space".
- A Restart button is always visible during a test; leaving mid-test loses nothing because nothing is saved.

### Result page pattern (same for all 7)

1. Headline result (one line, specific).
2. Score visual (bar, number or type badge).
3. What it means, in 2–3 short lines.
4. One "Try this" tip.
5. Bands disclaimer line.
6. Share card button + Try again button.
7. Next test suggestion + one Learn link.
8. FAQ + Sources.

### Footer line on every test page

"KnowPsyche tests are for learning and self-reflection. They are not medical or psychological assessments. If you're worried about your health or wellbeing, please speak to a qualified professional."

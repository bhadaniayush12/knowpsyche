# AdSense Site Readiness and Eligibility

## Scope

This file consolidates the supplied material covering:

- Make sure your site's pages are ready for AdSense
- Eligibility requirements for AdSense
- Owning the site you want to use to participate in AdSense

## 1. Pages should be ready for AdSense

For a site to succeed with AdSense, the supplied Google material states that it should have:

- Unique content relevant to visitors
- A good user experience

Before signing up, review whether the pages have:

- Something special or distinctive
- Clear, easy-to-use navigation
- Unique and interesting content
- Overall readiness for AdSense

## 2. What is special about the pages?

The supplied material emphasizes creating unique, original, relevant content that keeps users engaged.

Review:

- Arrangement of page elements such as text and images
- Whether the layout is inviting
- Whether visitors can easily find what they are searching for

The material also suggests considering a comment section.

### User-generated content

If comments are provided, the comment section needs moderation so it remains compliant with AdSense Program policies and free from inappropriate content.

## 3. Clear and easy-to-use navigation

Navigation is described as a key part of providing a good user experience.

When reviewing navigation, consider:

- **Alignment** — elements should be lined up correctly.
- **Readability** — navigation text should be easy to read.
- **Functionality** — drop-down lists and interactive navigation should work correctly.

The navigation should help users quickly understand how to interact with the site.

## 4. Unique and interesting content

The supplied material says valuable and original content is important for building a strong user base.

When using external resources such as:

- Articles from other sites
- Embedded videos
- Other third-party resources

The site should contribute its own original value, such as:

- Specialist knowledge
- Improvement ideas
- Reviews
- Personal thoughts
- Commentary
- Curation or other added value

### Scraped or copyrighted content

The supplied Google Publisher Policies material states that Google ads may not be placed on sites with scraped or copyrighted content.

This is treated as a policy issue that can lead to ads being disabled or an account being closed.

## 5. Eligibility requirements

The supplied eligibility material states that an applicant can sign up when:

- They have their own content
- Their content meets Google's policies
- They are at least 18 years old

### Unique and interesting content

The supplied material states that content must be:

- High-quality
- Original
- Able to attract an audience

### Site ownership / HTML access

The supplied material states that the publisher must be able to access the HTML source code of the submitted site.

The publisher needs to be able to place AdSense code between the `<head>` tags.

If the site is created with a CMS, HTML access may be provided through the CMS, plugin, or theme.

### Policy compliance

The publisher must comply with AdSense Program Policies before signing up.

The supplied material explicitly notes that Google may change policies at any time and that it is the publisher's responsibility to keep up to date with them.

### Age

The supplied material states that applications are accepted from applicants who are at least 18.

If an applicant is under 18, the supplied material states that a parent or guardian may sign up using their own Google Account, with payments made to the responsible adult if approved.

## 6. Owning the site

To use AdSense, the publisher must have access to the site's HTML source code.

The supplied material says the publisher must be able to place AdSense code between the `<head>` tags.

It also states that AdSense code may only be placed on a site that complies with AdSense Program Policies.

## 7. Google may change policies

The supplied materials repeatedly state that Google may change its policies and that publishers are responsible for keeping up to date.

Therefore, this local knowledge base should be treated as a reference snapshot, not a permanent guarantee of the current policy state.
